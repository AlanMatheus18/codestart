# CodeStart

Site estático de apresentação para o projeto `CodeStart`, uma landing page de cursos de programação com navegação responsiva, formulário de inscrição e layout moderno.

## Visão geral

Esta página foi criada como um projeto front-end com HTML, CSS e JavaScript puro. O objetivo é oferecer uma experiência visual clara e objetiva para divulgar cursos, depoimentos e contato, além de facilitar a inscrição de novos alunos.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5 (CSS)
- Lucide Icons
- EmailJS para envio de formulário
- Google Fonts (Orbitron e Montserrat)

## Estrutura do projeto

- `index.html` — página principal do site
- `css/` — arquivos de estilo divididos por seções e responsividade
- `js/` — scripts para menu mobile, formulário, pop-up e integração com via CEP
- `src/assets/` — imagens e recursos usados no layout

## Funcionalidades

- Menu responsivo para mobile e desktop
- Layout de seção `Sobre`, `Cursos`, `Depoimentos` e `Contato`
- Formulário de inscrição com envio via EmailJS

## Como usar

1. Abra o site `https://codestart-alan.netlify.app/` diretamente no navegador.
2. Ou sirva o projeto com um servidor local simples, por exemplo:
   - Usando VS Code Live Server
3. Navegue entre as seções e teste o formulário de contato.
